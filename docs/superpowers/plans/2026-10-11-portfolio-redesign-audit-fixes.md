- Initial JS ≤ 200 KB gz, 3D chunk ≤ 400 KB gz and lazy (`npm run budget`). Lighthouse mobile performance ≥ 0.90 (`npm run lhci`).
- Respect `prefers-reduced-motion`; Tier C has no motion layer.
- Tone (audit §4): calm authority, precise, no empty superlatives, no "not X but Y" cadence, no triads, no "real", no "ownership" outside Strengths.
